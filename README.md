# 🛡️ AstrBot 智能群管插件 (GroupGuardian)  @HS-lover 出品，感谢DeepSeek指导

基于 AstrBot V4 官方 API 开发的智能群管理插件。

## ✨ 功能

### 🤖 AI 自动管理
- **冲突检测**：自动识别群内吵架/冲突，AI 评估严重等级
- **智能警告**：冲突时自动 @ 双方发出警告
- **升级禁言**：警告后继续冲突自动禁言
- **刷屏检测**：自动识别并禁言刷屏用户

### 👮 手动管理指令

| 指令 | 说明 | 权限 |
|------|------|------|
| `/禁言 @xxx 60` | 禁言60秒 | 管理员 |
| `/解禁 @xxx` | 解除禁言 | 管理员 |
| `/踢人 @xxx` | 踢出群聊 | 管理员 |
| `/全体禁言` | 切换全体禁言 | 管理员 |
| `/群管白名单 add @xxx` | 添加白名单 | 管理员 |
| `/群管白名单 del @xxx` | 删除白名单 | 管理员 |
| `/群管白名单 list` | 查看白名单 | 管理员 |
| `/群管状态` | 查看运行状态 | 所有人 |
| `/群管帮助` | 查看帮助 | 所有人 |

## ⚙️ 配置

在 AstrBot Web 管理面板 → 插件设置中配置所有参数，包括：
- 管理员QQ号
- 白名单QQ号
- AI 冲突检测开关
- 自动警告/禁言开关
- 刷屏检测参数

## 🚀 安装

1. 将整个 `astrbot_plugin_group_guardian` 文件夹放入 `data/plugins/` 目录
2. 重启 AstrBot
3. 在管理面板设置管理员QQ号
4. 在群里发送 `/群管帮助` 测试
