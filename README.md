# 🎵 AstrBot 点歌插件 (MusicPlayer)

傻瓜式点歌插件，群友发送指令即可点歌，机器人自动搜索并以**语音形式**发送到群里。

## ✨ 功能指令

| 指令 | 说明 |
|------|------|
| `/点歌 歌曲名` | 搜索歌曲并发送语音 |
| `/搜歌 关键词` | 搜索歌曲列表（最多5首） |
| `/点歌id 序号` | 配合搜歌结果选择播放 |
| `/随机点歌` | 随机推荐热门歌曲 |
| `/点歌帮助` | 查看帮助信息 |

## 🚀 安装方法

1. 将整个 `astrbot_plugin_musicplayer` 文件夹放入 AstrBot 的 `plugins` 目录
2. 删除 `__pycache__` 缓存文件夹（如果有的话）
3. 重启 AstrBot
4. 完成！
